# Жоржина Рудрігес — догляд за рослинами

Mobile-first вебзастосунок українською (Vite + React + TypeScript + Tailwind). Без реєстрації й серверної БД: усі дані (рослини, журнал, фото) зберігаються в IndexedDB браузера на вашому пристрої.

**Сайт:** https://alexrud1993.github.io/zhorzhyna-rudriges/

## Телефон
- Відкрийте посилання в Chrome/Safari. Сайт працює по HTTPS, тому доступне встановлення на головний екран («Додати на головний екран»).
- **Розпізнавання за фото** — головна дія: велика кнопка з камерою в центрі нижньої панелі або блок «Розпізнати рослину за фото» на головній. Фото з камери чи галереї → варіанти з оцінкою сервісу → «Додати в колекцію» → готова картка рослини з фото.
- Автоматичне розпізнавання працює через захищений проксі (`proxy/`, Cloudflare Worker + Pl@ntNet). Поки проксі не підключено, сайт чесно про це каже і пропонує обрати рослину вручну — фото все одно потрапляє в картку. Як підключити — [proxy/README.md](proxy/README.md).
- Фото для картки зменшується до 800 px і зберігається лише на пристрої; на розпізнавання надсилається зменшена копія (до 1280 px).
- Дані не синхронізуються між пристроями: щоб перенести колекцію, використайте «Налаштування → Експорт / Імпорт JSON».

## Локальна розробка
```bash
npm install
npm run dev              # http://localhost:5173
npm run build            # tsc + vite build
npm run preview          # http://localhost:4173
npx playwright install chromium
npm run smoke            # CRUD, імпорт/експорт, 390/1280 px
npm run test:features    # погода, журнал, сховище, оцінка вологості
npm run test:identify    # розпізнавання (проксі підмінено), регресії QA
npm run test:proxy       # модульні тести проксі
```

## Що вміє
Каталог із 16 рослин (кімнатні, сад, город, дерева й кущі), додавання/редагування/видалення, журнал поливу й перевірок із скасуванням, календар, погода Open-Meteo для 5 міст з кешем і fallback, Простий/Розумний режими, ручна оцінка вологості ґрунту, експорт/імпорт з валідацією.

## Обмеження
- Підказки показують **орієнтовний час перевірки вологості ґрунту**, а не норму поливу; інтервали — загальні демо-значення, не агрономічна порада.
- Ключів API у коді сайту немає: ключ Pl@ntNet живе лише в секретах проксі. Результати розпізнавання — пропозиції, їх підтверджує користувач; демо-каталог має 16 видів + 4 загальні типи «Інша …».
- Офлайн-режиму (service worker) немає; погода кешується.
- Умови використання Open-Meteo слід перевірити перед комерційним запуском.
- `plant-care-ua` — історичний технічний ID IndexedDB та формату резервної копії, збережений для сумісності.
- `PROTOTYPE_SPEC.md` — історичне джерело вимог (стара назва в заголовку не є чинним брендом).
