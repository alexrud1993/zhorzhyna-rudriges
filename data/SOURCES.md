# Реєстр джерел даних і ліцензій (DB-006)

Перевірено 01.11.2026. Правило релізу (U2-1): використовуємо лише джерела, що **дозволяють майбутнє комерційне використання**. Ліцензії з умовою NonCommercial (NC) заборонені.

Машинний перелік дозволених доменів для `sources[].url` у картках — `scripts/data/lib/sources-registry.mjs`. Валідатор відхиляє картку, якщо джерело не з цього переліку.

## Дозволені джерела
| Джерело | Що беремо | Ліцензія | Комерція | Як перевірено |
|---|---|---|---|---|
| **GBIF Backbone Taxonomy** (doi:10.15468/39omei) | Прийняті назви, ранг, рід, родина, синоніми, GBIF ID | CC BY 4.0 | Так, з атрибуцією | API GBIF: поле `license` датасету `d7dddbf4-2cf0-4f39-9b2a-bb099caae36c` |
| **The World Checklist of Vascular Plants (WCVP)**, Royal Botanic Gardens, Kew | Таксономія (масове завантаження в наступних пакетах; зараз — через GBIF Backbone, що його включає) | CC BY 4.0 | Так, з атрибуцією | API GBIF: датасет `f382f0ce-323a-4091-bb9f-add557f3a9a2` |
| **Wikidata** | Українські назви (label, aliases), зв'язки GBIF / POWO / IPNI ID, GeoNames ID міст | CC0 (структуровані дані) | Так | API Wikidata `rightsinfo` |
| **Вікіпедія uk / en** | Тексти статей — **лише як джерело фактів** для ШІ-генерації | CC BY-SA 4.0 | Так. Умови: атрибуція; переписані близько до оригіналу тексти поширюються на тих самих умовах (ShareAlike) | API Вікіпедії `rightsinfo` (uk, en) |
| **GeoNames** | Населені пункти України, координати (GEO-001) | CC BY 4.0 | Так, з атрибуцією | `download.geonames.org/export/dump/readme.txt` |

**Наслідки CC BY-SA для карток:**
- Структуровані значення (числа, переліки) — це факти, і ShareAlike на них не поширюється.
- Текст `text_uk` генерується без дослівного копіювання: автоматична перевірка відхиляє будь-який збіг із 8 слів поспіль. Попри це, `textLicense` картки консервативно позначено `CC BY-SA 4.0`, а джерела перелічено в картці.
- Для комерційного релізу це прийнятно: умова SA вимагає відкритої ліцензії на тексти карток, але не забороняє комерцію.

## Виключені джерела
| Джерело | Причина виключення | Що натомість |
|---|---|---|
| **POWO (Plants of the World Online)**, тексти описів і зображення | Ліцензія залежить від конкретного постачальника даних; загальні умови сайту автоматично отримати неможливо (HTTP 403 на `/terms-and-conditions`, `/about`); сайт блокує автоматичний доступ. Комерційне використання похідних баз не підтверджене | Лише ідентифікатор POWO (через Wikidata, CC0) для посилань; таксономія — з WCVP / GBIF |
| **FAO Irrigation and Drainage Paper 56** (таблиці Kc, глибини коренів, p) | Публікації FAO захищені авторським правом: некомерційне використання з атрибуцією дозволене, комерційне відтворення — лише за ліцензійним запитом до FAO. Похідна база для майбутнього комерційного сервісу без дозволу заборонена | RULE-105 (водний баланс FAO-56) перенесено до 2.1. Можливі шляхи: дозвіл FAO або вільні джерела коефіцієнтів |

## Сервіси, безкоштовні лише для тестування (некомерційно)
Їх треба замінити платними планами перед комерційним запуском (OPEN-206):
| Сервіс | Використання | Умови безкоштовного рівня |
|---|---|---|
| **Pl@ntNet API** | Розпізнавання за фото (через проксі) | Некомерційне використання, ліміт на добу |
| **Open-Meteo** | Погода, ET0, мінімальна температура | Некомерційне використання, < 10 000 запитів на добу |
| **Gemini API** (безкоштовний рівень) | Пакетна генерація й рецензування карток | Низькі ліміти; Google може використовувати запити й відповіді для покращення продуктів, тому моделі передаються лише публічні тексти про рослини, жодних даних користувачів |
